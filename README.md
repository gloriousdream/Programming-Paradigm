# 🏰 部落冲突 (Clash of Clans) - Cocos2d-x 4.0

> 基于 Cocos2d-x 4.0 引擎开发的 2D 策略塔防/经营类游戏。
> 程序设计范式期末项目。

## 📖 项目简介

本项目是以经典游戏《部落冲突》为原版进行的复刻与开发。游戏采用 **Cocos2d-x 4.0** 引擎制作，核心玩法涵盖了**部落经营（造兵/建筑）**与**策略塔防（攻防战）**。

玩家可以在大本营场景中自由布局建筑、收集资源、训练士兵，并前往战斗场景挑战不同难度的关卡。项目实现了完整的游戏循环，注重代码规范与架构设计，适合作为 C++ 游戏开发的参考案例。

---

## 🎮 核心功能

### 1. 经营与建造系统
* **自由建造**：实现了基于网格的吸附与碰撞检测，支持建筑的自由放置与移动。
* **资源循环**：包含金矿/圣水收集器的生产、仓库存储以及基于资源的升级体系。
* **时间管理**：模拟真实的建筑施工时间，支持倒计时等待与加速水晶（立即完成）功能。
* **存档机制**：利用 `UserDefault` 实现本地数据持久化，保证资源与进度不丢失。

### 2. 策略战斗系统
* **多兵种 AI**：
    * **巨人 (Giant)**：高血量肉盾。
    * **炸弹人 (Bomber)**：特殊的自爆攻击模式（隐形-触发-爆炸）。
    * **弓箭手 (Archer)**：远程攻击机制。
* **智能寻路**：基于 A* 算法或方向向量的自动寻路逻辑。
* **防御塔逻辑**：加农炮/箭塔具备自动索敌与冷却机制。
* **难度分级**：提供简单、普通、困难三种战斗难度，动态调整敌人生成频率与属性。

### 3. 特色扩展功能
* **🎥 回放系统**：通过记录随机数种子 (Seed) 和操作时间戳，以极小的数据量完整复现整场战斗（`FightScene::createReplayScene`）。
* **🌤️ 昼夜交替**：基于时间累积动态调整遮罩层透明度，模拟真实的昼夜光照变化。
* **💣 陷阱系统**：实现了“隐形-触发-显形爆炸”的地雷逻辑，增加防守策略深度。
* **📱 跨平台适配**：代码完全基于 Cocos2d-x，采用通用触摸事件适配 Android/iOS 移动端。

## 💻 技术实现亮点 (C++ 特性)

本项目在开发过程中严格遵循 Google C++ Style，并广泛运用了现代 C++ 特性与设计模式。

### 1. 核心 C++ 特性
* **STL 容器应用**：
    * 使用 `std::vector` 存储寻路节点 (`Soldier.h`) 和回放操作序列 (`FightScene.h`)。
* **C++11/14 新特性**：
    * **Lambda 表达式**：用于 UI 回调与动作序列（如 `btnTrain->setCallback([=](Ref*){...})`）。
    * **Auto 类型推导**：简化复杂类型声明。
    * **Smart Pointers & Nullptr**：全面使用 `nullptr` 替代 `NULL`。
    * **Override**：显式标记虚函数重写，确保多态安全性。
* **异常处理**：
    * 在 `GameScene` 生成逻辑中加入了 `try-catch` 机制，防止非法区域生成导致的崩溃。
* **模板与泛型**：
    * 利用 `cocos2d::Vector<T>` 管理对象生命周期。

### 2. 架构设计模式
* **MVC 变体**：
    * **Model**: `SoldierManager`, `BuildingManager` (单例模式管理全局数据)。
    * **View**: `GameScene`, `BuildMenu` (渲染与交互)。
    * **Controller**: 实体类内部的状态机逻辑。
* **工厂模式 (Factory)**：
    * `SoldierManager::createSoldier` 通过 Type 参数动态创建不同兵种，极易扩展。
* **观察者模式 (Observer)**：
    * 利用 `EventDispatcher` 分发 `LOOT_GOLD_EVENT`，实现逻辑层与 UI 层的解耦。

### 3. 内存管理与优化
* **无内存泄漏**：全面采用 `cocos2d::Vector` 进行自动引用计数管理 (`retain`/`release`)。
* **安全的回调**：在异步 Lambda 中手动管理对象引用计数，防止目标死亡后回调访问野指针（如 `Cannon.cpp` 的炮弹逻辑）。
* **资源容错**：加载动画资源时实现了文件命名格式的自动降级查找。
